# Litnebula 界面设计

> 前端技术栈:React 19 + TypeScript + Vite 5(`frontend/`),3D 渲染用 Three.js;
> 构建产物由 FastAPI 托管(`frontend/dist`)。本文描述当前界面的视图、布局与交互。

## 1. 主视图:3D 球状星云

- 以 Three.js 渲染的全景星云:节点代表作者与作品,边代表连接关系。
- 节点样式:**作者 = 蓝白星**、**作品 = 金星**,均带光晕并随机呼吸闪烁。
- 边样式:
  - `AUTHORED_BY`(作品 → 作者)为暗淡弱连线;
  - `ECHO`(A 提及 B,方向 A → B)为青色发光星轨,沿 A → B 流动的"流星"光尾
    (头亮尾暗的渐变短光线)表达方向。
- 背景:CSS 星群 + 流星 + 星云渐变(深邃星空氛围)。

## 2. 视图

| 视图 | 说明 |
|---|---|
| 主图谱 | 全量球状星云,作者与作品节点同屏 |
| 涟漪 | 以某作品为中心的 3D 扩散球(N 级扩散,滑动条 1-8 级) |
| 提及链 | 两作品间的 3D 提及路径(螺旋排列,有向最短链) |
| 作者 | 作者居中,其全部作品环绕 |

- 顶部/侧栏有视图状态指示条(如「涟漪 ·《X》」「作者 · X」),toast 反馈操作结果。
- 支持开关:「隐藏孤岛星」(`islands=1`)、「隐藏作者节点」(`authors=0`)。

## 3. 布局

- **左侧功能栏**(类 VS Code 侧边栏,悬浮于屏幕边缘):Tab 列「星云 / 我的 / 消息 / 设置」。
  - 星云:搜索、路径输入(边输入边联想 + 交换按钮)、返回全部图谱、扩散范围滑动条、点亮星空、数据管理;
  - 我的:个人资料编辑(昵称/简介)+ 关注/粉丝列表(可跳转对方星云);
  - 消息:占位(第二阶段通知,暂未实现);
  - 设置:星云可见性(公开/仅自己可见)、退出登录(未登录时提供登录/注册)。
- **右侧详情栏**(同样 Tab 列):「涟漪」(当前视图内容)/「书签」(所选作品的评分/评价/阅读状态)/
  「个人资料」(当前星云所有者的昵称与简介)。
- 左右侧栏右上角各有「📌 钉住」按钮:钉住后不再随移出/计时自动隐藏,状态记忆在 localStorage。
- 鼠标移到屏幕边缘感应带(◀/▶)滑出侧栏,移出收回。

## 4. 交互

- 图谱:右键拖拽旋转、左键拖拽平移、滚轮缩放(相机距离 50-8000);点击作品星进入涟漪视图,
  点击作者星进入作者视图;悬停节点暂停自动旋转并滑出详情(不切换视图);交互停止 500ms 后自动恢复旋转。
- 触摸:单指平移、双指旋转 / 缩放。
- 搜索下拉:↑↓ 选择、Enter 确认;路径输入回车查询。
- 首访引导卡(可关闭,localStorage 记忆,`?skipguide=1` 跳过)。

## 5. 数据管理页

- 对所有登录用户开放:作者/作品/涟漪三个 Tab 管理**自己的星云**;
  admin 额外拥有「日志 / 快照 / AI草稿」三个平台级 Tab。
- 表格:表头点击排序、筛选行(下拉枚举 + 按列搜索)、软删除/恢复按钮。
- 表单:标准新增/编辑弹窗(NodeFormModal,数据管理与点亮星空共用),枚举下拉、作者/作品选择器、
  必填校验;新增时原文名/原著标题联想本空间已有数据,命中已存在数据时禁止保存。
- 「AI草稿」Tab:按导入批次(源书)分组展示**自己上传**的 AI 提取草稿
  (owner_id=上传者 + created_by='llm' 隔离),每条涟漪用「点亮星空」同款字段
  (源作品/源作者/目标作品/目标作者/原文片段/出处/备注)展示,可独立批准
  (依赖的作者/作品自动建库,与公共星云精确重复时自动复用现有记录并提示,
  同名异书/可能重复仍走新建)、驳回/重开、编辑(标准编辑弹窗);
  批准后进入「已发布」折叠区;右上角「清空」按钮确认后软删除自己上传的全部草稿。
- 导入:作者/作品/涟漪/AI草稿页签均显示「导入」按钮(admin/VIP),AI 草稿页
  导入完成后草稿列表自动刷新。

## 6. 深链与 URL 参数

- `#v=main` / `#v=path:{fromId},{toId}` / `#v=ripple:{workId}:{hops}` / `#v=author:{authorId}`
- `islands=1`(隐藏孤岛星)、`authors=0`(隐藏作者节点)
- `space=public|mine|<用户id>`(当前星云,刷新/分享后保持)
- `cam=theta,phi,radius,cx,cy,cz`(相机位置,旧版分享链接格式,兼容解析)
- 旧格式 `#path=` / `#ripple=` / `#author=` 已移除,统一 `#v=` 格式;标识均为 UUID。

## 7. 移动端

- 左侧功能栏横向顶栏;栏外点击收起;钉住状态同样生效。
- 手势支持单指平移、双指旋转/缩放。
