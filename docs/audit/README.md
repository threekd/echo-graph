## 已修复的问题类型(防复发清单)

1. **配置前后矛盾**:`.env.example` 默认值与 README/生产预期不一致
   (曾导致新部署呈现近空图)。→ 修复:默认值统一,上线清单明确「逐条审核后开启」。
2. **本地环境残留**:venv 中残留已退役依赖、已删除模块的 `__pycache__`。
   → 修复:`uv sync --frozen` 清理,删除残留 `.pyc`。
3. **限流信任边界**:直接信任 `X-Forwarded-For` 可被伪造绕过限流。
   → 修复:`TRUSTED_PROXIES` 白名单,仅可信代理采信代理头;nginx 加 `limit_req`。
4. **公开读每请求全量载入**:→ 修复:进程内读缓存(TTL 3s,写后失效)+ 索引;
   FTS5 留作数据量增长后演进。
5. **列定义重复**:`sqlite_store` 与 `data_store` 两处表头。→ 修复:单一来源派生。
6. **测试专用代码躺在生产模块**:`rewrite_all` 等。→ 修复:移入 `tests/_helpers.py`。
7. **文档过期/重复**:README 重复段落、历史文档残留旧架构描述。
   → 修复:文档同步维护,历史档案单独标注(2026-08-29 进一步整体精简)。
8. **CI 门禁红色**:ruff 报错集中在一次性脚本。→ 修复:删除/修复脚本,门禁恢复绿色。
9. **`.env.example` 缺配置项**:AI 管线 `DEEPSEEK_*` / `ALIYUN_*` 未收录。
   → 修复:补入模板并注明用途。
10. **快照/审计无保留策略**:→ 修复:快照保留 30 份,`scripts/prune_audit.py` 裁剪审计。
11. **恢复并发窗口**:文件替换恢复可能产生瞬时不一致。→ 修复:SQLite backup API 覆盖 +
    `_write_lock` 互斥 + 「恢复期间请勿编辑」提示。
12. **私有成员跨模块导入**:`from app.space_crud import _after_write`。
    → 修复:提升为公共名 `after_write`。
