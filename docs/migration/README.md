# 架构演进档案

> 历史档案:记录 2026-08-21 ~ 2026-08-28 的架构演进过程与关键决策。
> 详细过程在 git 历史中可查,本文只保留**当前仍有参考价值的结论**;
> 描述已退役系统(Neo4j、CSV 事实源、公共星云等)的旧文档已删除。

## 演进时间线(摘要)

| 时间 | 演进 | 结论(当前有效) |
|---|---|---|
| 2026-08-21 | Neo4j 查询层与 JSON 兜底退役,SQLite 承担全部读写 | SQLite 是唯一权威;输出形状稳定,前端无需感知存储层 |
| 2026-08-22 | 多用户空间隔离 + 角色迁移 | 业务表 `owner_id` 隔离,`/api/me/*` 仅本人、`/api/space/*` 按可见性 |
| 2026-08-23 | 只读路由收敛为工厂 | `/api/me` 与 `/api/space` 共用一份实现,不再三套并行 |
| 2026-08-24 | 移除贡献收件箱(schema v22) | 「点亮星空」直写个人空间;不再有收件箱审核通道 |
| 2026-08-25 | admin 用户管理 + AI 草稿审核管道 | 上传者=审核者=发布到自己星云;`published_to_id` 防重复发布 |
| 2026-08-27 | CSV 备份层移除 | 备份统一为**整库快照**(`sqlite3 .backup` + 管理端恢复) |
| 2026-08-28 | 公共星云/官方图谱概念移除 | 不存在默认视图;admin 星云与其他用户星云语义一致;引导管理员仅保留首个 admin 引导 |
| 2026-08-28 | 邮箱验证 + 密码重置 | 引导管理员验证通过后才提权;一次性令牌只存哈希 |

## 关键架构决策(当前仍生效)

1. **SQLite 唯一权威**,WAL + 单写事务 + `PRAGMA foreign_keys=ON`;备份走整库快照,
   不再有 CSV 导出层(曾因多设备/调试导致漂移)。
2. **单 worker 是设计约束**:进程内限流/读缓存/写锁都依赖单进程语义;多 worker 需换
   Redis 等共享存储。
3. **隔离在查询层强制**:所有空间读取必须带 `owner_id`,漏配返回空而非泄露;
   越权一律 404,不暴露存在性。
4. **读缓存 3 秒 TTL + 写后失效**:键含 DB 路径 + owner,admin 写/快照恢复显式失效。
5. **AI 草稿三阶段去重**(基础 + 语义嵌入 + LLM 兜底确认),判重目标 = 用户自己星云。
6. **手工新增/编辑一律 `reviewed`**(输入即确认),审核状态只对 AI 提取草稿有意义。

## 可复用的教训

- 存储/查询层退役时,保持 API 输出形状不变,前端可零改动过渡;
- 多套数据表示并存(写库 + 查询层 + 导出 + 兜底种子)是漂移的主要来源,能收敛就收敛;
- 迁移与一次性脚本用完后立即删除(曾出现拖垮 lint 的一次性脚本残留);
- 文档在架构变更当天同步更新,避免「历史记录」与现状混淆。
