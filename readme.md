**项目全称**  
The Echo Graph — A Ripple Atlas of World Literature  
中文名：**回声图谱——世界文学的涟漪地图**

**一句话定义**  
以“回声”为链接隐喻、“涟漪”为传播隐喻，构建一张跨语言、跨文化的世界文学影响图谱，让人清晰看见一部作品、一位作家如何穿越时间与语言，在后世产生回响与传承。

**核心概念**
- **回声（Echo）**：每一次引用、致敬、反驳，都是一部作品在另一部作品中的再次发声。
- **涟漪（Ripple）**：思想从中心向外扩散，在异时、异地、异语中激起新的创作。
- **传承（Heirloom）**：作家不是凭空诞生，每部作品都继承了前人的遗产，并把它交给来者。

**核心价值**
为文学研究者和爱好者提供一种全新的交互方式，用来探索：
- 哪些作家影响了哪些作家？
- 一部作品如何从母国传播到他国？
- 思想在跨语言传播中发生了怎样的变形？
- 是否存在被遗忘的重要“回声链”？

**目标用户**
- 比较文学研究者、翻译研究者
- 数字人文、计算文学研究者
- 高校师生、文学爱好者
- 出版社、文学策展人

**核心功能**
1. **影响力图谱**：以节点代表作家/作品，边代表影响关系（引用、致敬、回应等），支持点击展开、拖拽浏览。
2. **时间涟漪视图**：选择一部作品，按时间轴动态展示其影响如何像涟漪一样向外扩散。
3. **跨语言路径**：输入任意两部作品，计算并展示它们之间的影响传播链（如“维吉尔 → 但丁 → 艾略特 → 帕斯”）。
4. **关系类型筛选**：区分直接引用、间接影响、翻译中介、创作回应等，让影响方向更具体。
5. **来源追溯**：每条关系都附有出处、证据与置信度，保证学术严谨性。

**技术架构建议**
- 数据存储：Neo4j 图数据库 + PostgreSQL
- 后端：Python / FastAPI，提供查询路径、扩散计算、影响力算法
- 前端：React + AntV G6 或 Three.js，支持大数据量图谱可视化
- 运维：Docker + K8s，可部署至 GitHub Pages / 云服务器

## 实施路线

整个项目建议分四个阶段，总计 **12 个月** 左右完成。每个阶段都有明确的交付物与验证标准。

### 阶段一：概念验证（0–3 个月）

**目标：** 搭建最小可行版本，验证“回声图谱”被用户理解和接受。

**主要任务：**
- 定义数据模型：作家、作品、关系类型、属性字段。
- 初始数据集：选取 **500位核心作家 + 1000部经典作品**，从 Wikidata / Open Library 拉取基础信息。
- 人工策展 **50条高置信度影响链**，作为种子数据。例如：
  - 杜甫 → 白居易 → 松尾芭蕉 → 庞德
  - 曹雪芹 → 张爱玲 → 白先勇
  - 莎士比亚 → 艾略特 → 博尔赫斯
- 搭建 Neo4j 图数据库，导入数据。
- 开发基础 API：查询一个作家/作品的一阶邻居、查找两点间最短路径。
- 开发一个简单前端页面，可视化种子图谱。

**验证标准：**
- 邀请 5–8 位文学研究者试用，反馈是否在读图中发现了有意思的链接。
- 确认“回声”和“涟漪”的隐喻能有效被理解。

---

### 阶段二：核心功能搭建（3–6 个月）

**目标：** 实现最吸引人、最核心的两个功能——时间涟漪与跨语言路径。

**主要任务：**
- 扩展数据规模至 **2000位作家 / 5000部作品**，覆盖更多非欧洲语言地区（东亚、南亚、中东等）。
- 为每条关系增加时间属性、语言属性、关系强度与来源。
- 实现**时间轴滑块**：用户可以拖动时间，动态过滤图谱上所有影响关系。
- 实现**涟漪视图**：选择一部作品后，按照年份向外展示所有受影响的后续作品。
- 实现**跨语言路径搜索**：支持任意两个作品，返回“最短影响链”或“最有意义影响链”。
- 界面优化：增加中英文检索、自动补全、关系图例。

**验证标准：**
- 能完整演示一条跨语言影响链，例如：
  《源氏物语》→ 英译本（Waley）→ 艾兹拉·庞德 → 现代主义诗歌。
- 用户可以在 3 步以内完成一次搜索并看到可视化结果。

---

### 阶段三：算法与洞察深化（6–9 个月）

**目标：** 不仅可视化已知关系，还要自动发现隐藏的回声。

**主要任务：**
- 实现 **影响力排名算法**（如改进型 PageRank），计算作家影响力在跨语言中的传播衰减。
- 实现 **社区检测**，自动聚类出思想圈层（如“浪漫主义网络”“拉美魔幻现实主义圈层”）。
- 开发 **回声链生成器**：输入一个作家，输出一份“传承报告”，列出他的思想源头与后裔。
- 可选实验：对公开版语料进行文本相似度计算，尝试发现没有显式引用但主题呼应的作品。
- 和学者合作，验证算法发现的链接是否具有学术价值。

**验证标准：**
- 算法能准确识别出如“博尔赫斯 → 卡尔维诺 → 村上春树”这类已有公论的影响链。
- 能输出一份“意想不到的回声”列表，并由学者判断是否可信。

---

### 阶段四：产品上线与传播（9–12 个月）

**目标：** 让项目成为一个公开可访问的、持续维护的文化平台。

**主要任务：**
- 全面优化视觉设计，补充移动端适配。
- 构建网站：包含首页、图谱交互页、关于我们、方法论、数据来源说明。
- 开发**用户提交功能**：学者或资深读者可提交新的影响关系，附加证据，经审核后加入图谱。
- 将数据导出为JSON / CSV，开放API，支持学术使用。
- 撰写论文或预印本（面向 DH 数字人文会议或 JOCCH 等期刊）。
- 联系比较文学系、翻译系、图书馆，合作推广。

**验证标准：**
- 平台上线后 6 个月内获得 1000+ 注册用户。
- 收到至少 10 条来自不同国家/语系的专家策展补充数据。
- 论文被学术会议或期刊接受。

## 风险与应对

| 风险 | 应对 |
|---|---|
| 数据主观性强，影响关系难界定 | 每条边必须标注来源，设置置信度，支持证据链接 |
| 早期数据稀疏，用户觉得空 | 先用经典文学史公认关系做厚，再做广 |
| 可视化卡顿 | 分层渲染，只在需要时加载更多节点 |
| 社区贡献质量参差 | 审核制，优先邀请专家，后续开放众包 |

---

## 结语

The Echo Graph 的最终形态，不是一张静态网络图，而是一个**可以阅读的文学宇宙**。它让那些藏在大师背后的名字重新浮现，让跨越语言与时代的传承被看见。如果用一句话来形容这个项目，那就是：

> **每一本书，都是前人落在水中的石子；而整个文学史，是一片交织的涟漪。**
